## Про две ссылки

Запрошены были две страницы:

- `https://crossmark.ru/` — главная, отдаётся с серверным рендером, текст снят прямо из HTML.
- `https://crossmark.ru/test/landing-glass` — **это тот же лендинг с тем же текстом**, отличается только оформлением. В коде роут `/test/landing-glass` вешает на страницу CSS-класс `landing-glass` и рендерит тот же компонент с теми же данными, что и главная. Отдельного текста у этой страницы нет.

Проверено по бандлу `/assets/index-BzhVC8fA.js`: маршрут `/test/landing-glass` → компонент, который добавляет класс и вызывает ту же сборку секций (hero, problem, how, tech, cases, pricing, faq) с теми же переменными контента. Контр-проверка: если бы копия различалась, в бандле нашёлся бы второй набор маркетинговых строк — его там нет, все найденные строки совпадают с текстом главной, лишние — только служебные (формы, чат, alt).

Оговорка: страницу `/test/landing-glass` не удалось открыть в браузере — MCP-браузер был занят другой сессией, поэтому вывод сделан по коду, а не по рендеру. Если нужно убедиться глазами — открыть её в свободной сессии и сверить с `01-landing-copy.md`.

## Что не снималось

Только главная. Отдельные страницы `/about`, `/how-it-works`, `/tarify`, `/faq`, `/cases`, `/partners`, `/blog` не трогали — их не просили. Отзывы в блоке «Кейсы» подгружаются с сервера и в слепок не попали (в HTML на их месте «Загружаем отзывы…»).
