# Витрина макетов — что здесь лежит

## ✅ Финальная версия лендинга

**[hero-final/lending-tech.html](hero-final/lending-tech.html)** — состояние на 20 августа 2026.

Полная страница в направлении «Ночная редакция»: тёмно-синяя подложка, янтарный акцент,
стекло, свечение и движение. Первый экран → неделя разведки → ядро и структура → контент-завод →
разметка страницы → круглосуточная смена → кабинет клиента → финал.

Открывается двойным кликом, без сборки и интернета (шрифты подтягиваются с Google Fonts).

## Правило при правках

Тексты и порядок блоков в `lending-tech.html` и `lending.html` одинаковые — различается только
оформление. Правку текста вносить в оба файла, иначе версии разъедутся.

Что доказывает каждый блок и какие границы удержаны в формулировках —
