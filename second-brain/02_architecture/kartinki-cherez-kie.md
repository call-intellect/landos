# Картинки через kie.ai

**Возможность есть и проверена живым вызовом 2026-08-30.** Мы умеем заказывать картинки под витрину
и лендинги — из текста и по референсу — не выходя из проекта: `node tools/kartinki/kie-image.mjs`.
Раньше это жило только в чужом репозитории `call-intellect/vibe-seo`; здесь лежит свой тонкий клиент.

## Две модели, а не одна

| Что нужно | Модель | Чем кормить |
|---|---|---|
| Придумать картинку с нуля | `gpt-image-2-text-to-image` | только `prompt` |
| Переделать существующую, сохранив композицию | `gpt-image-2-image-to-image` | `prompt` + `input_urls` — до 16 **публичных** ссылок |

Скрипт выбирает модель сам: есть хоть один `--ref` → вторая, нет → первая. Локальный файл в публичную
ссылку он превращает сам, заливая на файловый хост вендора.

## Команды

```
node tools/kartinki/kie-image.mjs --prompt "текст" --out kartinka.png
node tools/kartinki/kie-image.mjs --prompt "перекрась в красное" --ref ishodnik.png --out novaya.png
node tools/kartinki/kie-image.mjs --prompt "герой лендинга" --aspect 16:9 --resolution 4K --out geroj.png
```

Дефолты: `--aspect 1:1`, `--resolution 1K` — самое дешёвое, годится для проб и иконок.
Под герой-блок витрины брать `16:9` и `4K`.

## Цена и время — замер, а не оценка

Обе модели прогнаны 2026-08-30 на `1:1 / 1K`: **~60 секунд и 6 кредитов ≈ 2,3 ₽ за картинку**,
одинаково для текстовой и референсной. Курс — 0,3916 ₽ за кредит. Скрипт печатает баланс до и после,
так что расход виден по факту, а не по прайсу.

Замер image-to-image заодно доказал, что референс действительно берётся: та же звезда сменила цвет,
но форма и композиция совпали пиксель в пиксель — значит вендор правил исходник, а не рисовал заново.

## Ключ

Секрет один — `KIE_API_KEY`, скрипт ищет его в переменных окружения и в `.env` корня проекта
(понимает также имена `KIEAI_API_KEY`, `KIE_AI_API_KEY`, `KIE_KEY`, `FACTORY_KIE_API_KEY`).
Значение `CHANGEME` считается отсутствующим — см. грабли ниже.

Источник ключа — сервер `46.8.196.29` (хост `vibeceh-prod` в `~/.ssh/config`), файл
`/home/docker/statejnik/apps/stateinik-engine/.env`, читается через `sudo`.

## Грабли, на которые уже наступили

| Симптом | Причина | Как правильно |
|---|---|---|
| Ключ «есть», а вендор отказывает | в `/home/user/.env` на сервере лежит `KIE_API_KEY=CHANGEME` — заглушка, и она находится первой | брать ключ только из `statejnik/apps/stateinik-engine/.env` под `sudo`; скрипт `CHANGEME` игнорирует |
| Картинка молча вышла мельче заказанной | вендор тихо отдаёт класс разрешения ниже запрошенного | сверять ширину результата с заказанным `--resolution`, у донора порог 3400 px для `4K` |
| Соблазн повторить упавший запрос | «запрос ушёл, ответа нет» — задачу могли принять и затарифицировать | вслепую не повторять; сперва искать задачу опросом, иначе платим дважды |

## Что здесь намеренно тонко

Клиент в `tools/kartinki/` — один файл без зависимостей, только `fetch` и `node:fs`. Полновесный
образец с ретраями вендора, нарезкой листа 2×2 и проверкой пропорций живёт в `apps/image-lab/`
репозитория `call-intellect/vibe-seo` — если понадобится комплект картинок к статье одним вызовом,
брать оттуда, а не дописывать этот.
