# 05_history — рефлексия после каждого push

## Когда писать

После **каждого** `git push` (и по триггеру «закругляемся / спасибо / ок»). Один файл — одна сессия работы.

## Имя и frontmatter

- Имя файла: `YYYY-MM-DD-краткое-название.md`.
- Frontmatter:
  ```
  ---
  distilled: false
  ---
  ```

## Структура рефлексии

1. **Что было поставлено** — задача одним абзацем.
2. **Как решал** — ход работы с конкретными файлами (`path:line`) и коммитами.
3. **Что вышло** — результаты верификации: сборка, тесты, ручная проверка.
4. **Чему научился** — урок (даже маленький).

## Триггер дистилляции: > 10 файлов без `distilled: true`

Когда в папке накопилось > 10 необработанных рефлексий (без `distilled: true` во frontmatter),
перед новой задачей пройдись по ним и вынеси **повторяющиеся** уроки:

| Тип урока | Куда переносить |
|---|---|
| Техническая грабля проекта (ловушки типов/сборки/БД/фреймворка, контракты) | `02_architecture/code-pitfalls.md` |
| Поведенческое правило для агента | память агента (см. правило завершения работы в CLAUDE.md) |
| Правило про конкретный модуль | профильная `01_projects/<feature>.md` |

Критерий переноса (хотя бы один): урок повторяется в ≥2 рефлексиях, ИЛИ цена > 1 часа, ИЛИ меняет способ работы.

После переноса — проставь `distilled: true` в обработанных файлах. **Файлы НЕ удалять** — это контекст-источник для будущей дистилляции.
