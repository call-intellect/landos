# Разбор визуальной системы reg.ru (внешний референс)

> Отвечает на вопрос: из каких именно правил собран сайт reg.ru и что из этого переносимо.
> Все значения сняты из `getComputedStyle` живой страницы, не с картинок.

## 0. Одной фразой

Светлое холодное поле, на котором лежат **скруглённые плиты-острова** (белые, серые, чёрные,
мятно-зелёные). Разделение слоёв — цветом, а не тенью. Один акцентный цвет. Один шрифт в двух
весах. Лестница радиусов, привязанная к размеру объекта.

## 1. Шрифт и типографика

| Что | Значение |
|---|---|
| Гарнитура | `Geologica` (self-hosted, `img.reg.ru/news/Geologica-*.woff2`), fallback `Inter, Arial, Helvetica Neue, FreeSans` |
| Веса в проде | **только 300 (Light) и 500 (Medium)**. 700 на главной нет |
| Трекинг заголовков | `-0.03em` (H1–H3, H5), `-0.02em` (H4, H6, H7) |
| Трекинг текста | `-0.02em` — то есть `16px → -0.32px` |
| `font-display` | `swap` |

Контраст между заголовком и текстом строится **размером, а не жирностью**: 50px/Medium против
16px/Light. Это и даёт «дорогой» вид без единого Bold.

Шкала (десктоп M, 1280–1599 px):

| Роль | size/line-height |
|---|---|
| H1 | 72/80 (desktop-L 84/93, desktop-S 60/66) |
| H2 | 50/55 |
| H3 | 48/53 |
| H4 | 32/36 |
| H5 | 24/32 |
| H6 | 20/24 |
| H7 | 16/20 |
| text L | 20/24 → 22/27 → 24/29 |
| text M | 16/20 → 18/22 |
| text S | 16/20 |
| text XS | 14/17 |
| text XXS | 12/15 |

Фактически на главной: заголовки секций `50/55 · -1.5px`, титул крупной карточки `48/53 · -1.44px`,
титул мелкой карточки `24/32 · -0.72px`, корпус `16/20 w300`.

## 2. Цвет

Полная палитра — 464 CSS-переменные, но **на главной работает восемь значений**.

| Роль | HEX |
|---|---|
| Акцент бренда («мята») | `#1EDE7B` · hover `#1AC16B` · dark `#149955` |
| Чернила — текст и primary-кнопка | `#2B2F33` |
| Чернила — заголовки и тёмные плиты | `#191B1E` |
| Футер | `#181818` |
| Главный светлый фон | `#F2F4F7` |
| Карточка на светлом фоне | `#F9FAFC` |
| Белая карточка | `#FFFFFF` |
| Вторичный текст | `#707A8A` |
| Разделитель | `#DFE3E8` · граница контрола `#CBCDD6` |

**Ключевое наблюдение: главная кнопка НЕ зелёная, а чёрная** (`#2B2F33`, белый текст). Зелёный
работает как заливка плиты и как цвет текста-акцента/ссылки, но не как CTA. Это ломает шаблон
«зелёный бренд → зелёная кнопка» и делает зелёный редким, а потому заметным.

Второстепенные цвета (`#FFD11A` жёлтый, `#FF2D50` красный, `#FF3366` малиновый, `#8F7EFF`
фиолетовый, `#DCFFA0` салатовый) живут **только в иллюстрациях и статус-тегах**, в вёрстке их нет.

## 3. Скругления — лестница по размеру объекта

| Радиус | Кому |
|---|---|
| 8px | кнопки, инпуты, мелкие контролы |
| 12px | мелкие блоки, ghost-кнопки |
| 24px | карточка товара, карточка оффера — **рабочая лошадь** |
| 32px | крупная медиа-карточка |
| 40px | плита секции, подложка hero |
| 64px | гигантские плиты: «Рег.решения», «Облако», футер |
| 100px (pill) | теги, доменные чипы |

Правило: **радиус растёт вместе с плоскостью**, ориентировочно ~5 % ширины блока. Мелочь скруглена
мягко, гигантские плиты — очень сильно.

Приём «составная капсула»: зелёная шапка `border-radius: 64px 64px 0 0`, а её светлое продолжение
`0 0 64px 64px`. Два блока стыкуются в одну капсулу с прямым швом посередине.

## 4. Тени и границы

- На всей странице **одна тень**: `rgba(0,51,153,.08) 0 4px 8px`. Токены теней в системе есть
  (все синеватые, `rgba(0,51,153,*)`, не чёрные), но на главной практически не применены.
- Слои разделяются **цветом**: карточка `#F9FAFC` на фоне `#F2F4F7`, белая карточка на `#F2F4F7`.
- Границы `1px #CBCDD6` — только теги-пилюли и вторичные кнопки.
- Внутри тёмных плит границы `rgba(255,255,255,.05)` и `rgba(255,255,255,.2)`.

## 6. Приём «фото в паспарту»

Карточка товара устроена так:

```
.product-card            radius 24, bg #F9FAFC
  └ .product-card__image-wrapper   padding: 8px 8px 0 8px
       └ .product-card__image      radius 24
```

Картинка вложена с полем 8px и **со своим собственным скруглением 24px**. Внешнее и внутреннее
скругление одинаковые, поле тонкое — получается эффект наклеенного стикера. Это самая
узнаваемая деталь их карточек, и она дешевле любой тени.

## 7. Картинки: что растр, а что SVG

| Тип | Кол-во | Роль |
|---|---|---|
| inline `<svg>` | 61 | все иконки; спрайта нет (`<use>` = 0) |
| `.webp` | 28 | все иллюстрации, фото, скриншоты, баннеры |
| `.svg` как `<img>` | 4 | логотипы |
| `<picture>` | 14 | отдельный мобильный кроп через `srcset` |
| CSS `background-image` | 3 | подложки hero, баннера, блока «Облако» — тоже webp |
| CSS-градиенты | **0** | все переливы «запечены» в растр |

Размеры исходников: продуктовые 3D-иконки **448×448** (квадрат, прозрачный фон, лежат на цветной
плашке), карточки товаров **570×428**, hero-фото **1452×1452**, баннер 3600×540.

Вывод для воспроизведения: их визуал держится на двух видах картинок — **квадратные 3D-рендеры
объектов с прозрачностью** и **скриншоты интерфейсов в перспективе**. Ни то ни другое не рисуется
кодом; под это нужен генератор изображений.

## 8. Движение

| Что | Значение |
|---|---|
| Смена состояния | 0.05 / **0.1** / 0.2 s, easing `cubic-bezier(.45,0,.55,1)` |
| Появление | 0.15 / **0.3** / 0.5 s, easing `cubic-bezier(.81,0,.04,1)` |
| Уход | 0.05 / 0.2 / 0.3 s, easing `cubic-bezier(.25,.01,.47,.99)` |

Практически: ховеры — `color` / `background-color` / `opacity` за 0.1s, `transform` за 0.3s,
`box-shadow` 0.3s linear. Никаких пружин и подпрыгиваний.

## 9. Что переносимо, а что нет

Переносимо (система приёмов, она нейтральна к палитре):

- лестница радиусов по размеру объекта;
- разделение слоёв цветом вместо теней;
- два веса шрифта и отрицательный трекинг;
- плиты-острова внутри общего поля вместо полос на всю ширину;
- «фото в паспарту» с одинаковым внешним и внутренним радиусом;
- нейтральная кнопка при ярком бренд-цвете.

Не переносимо в наш лендинг: сама палитра и гротеск. Наше направление —
[[hero-visual-direction|«Ночная редакция»]]: тёмная гамма, янтарный акцент, серифная
типографика. Reg.ru — её прямая противоположность (светлое поле, мята, гротеск). Смешение
развалит утверждённое владельцем направление, поэтому копия reg.ru — **отдельная витрина**,
а не источник правок для нашего лендинга.
