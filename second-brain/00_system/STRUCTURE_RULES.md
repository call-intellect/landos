# STRUCTURE RULES

## Структура папок

```
second-brain/
├── index.md              ← единственная точка входа
├── 00_system/            ← протоколы и правила (этот уровень)
├── 01_projects/          ← заметки по фичам и модулям
├── 02_architecture/      ← архитектурные решения (ADR), карта модулей, модель данных
├── 03_processes/         ← сквозные процессы и регламенты
├── 04_not-done/          ← реестр отложенного и пробелов (с причиной)
├── 05_history/           ← рефлексия после push
└── 13_glossary/          ← глоссарий терминов
```

> Опционально: `06_marketing/` (позиционирование/messaging) — добавляй только для продуктовых проектов.
> Форма и когда заводить — в `06_marketing/README.md`.

## Что куда: знание против планов

Развилка одна — «это работает или это идея?». Работает по факту → `second-brain/`; пока замысел →
`plans/`.

| Что | Куда |
|---|---|
| Что работает по факту, архитектура, сущности | `second-brain/` (`01_projects/`, `02_architecture/`) |
| История сессий, рефлексия | `second-brain/05_history/` |
| Намеренно НЕ сделанное / отложенное (с причиной) | `second-brain/04_not-done/` |
| Анализ фичи, UX-аудит, backlog | `plans/analysis/` |
| Архитектура человеческим языком (владелец одобряет ДО ТЗ) | `plans/architecture/` |
| ТЗ на реализацию | `plans/tz/` |
| Передача следующему звену цепочки | `plans/handoff/` |

## Как завести новую доменную папку (07/08/…)

Таксономия — фикс-ядро + ручной опт-ин: новую папку верхнего уровня заводит агент осознанным актом,
сама она не появляется. Завёл папку — сделай **оба** шага, иначе она будет «невидимкой» для поиска:

1. **Зарегистрируй секцию в `index.md`** — папка без секции в индексе не существует (`INDEX_RULES.md`).
2. **Пропиши вес секции в движке** — `RepoBrain/packages/memory/src/index.ts`, функция `sectionWeight`
   (switch по номеру папки). Без строки веса секция получает дефолт `1.0`. Движок знает номера `00–06`;
   для `07+` вес нужно добавить руками, иначе новые заметки не поднимутся/не опустятся в ранжировании.
   Ориентир ярусов: архитектура/проекты — высоко (1.4–1.5), справочное — 1.1–1.3, система/история — низко (0.6–0.7).

## Именование файлов
- Протоколы: `UPPER_CASE.md`
- Заметки: `kebab-case.md`
- ADR: `ADR-001-название.md`
- Рефлексия: `YYYY-MM-DD-краткое-название.md`

## Правила
- Один файл = одна тема
- Файл без ссылки в index.md не существует
- Не создавать вложенность глубже 2 уровней
