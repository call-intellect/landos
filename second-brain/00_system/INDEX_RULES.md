# INDEX RULES

## Где регистрируется новый файл

**В под-индексе своей папки** — `second-brain/NN_*/index.md`, строкой
`- [[файл|Заголовок]] — отвечает на вопрос: …`. Создал файл — сразу строка; удалил — убрал; переименовал — поправил.

В корневом `second-brain/index.md` регистрируется **папка, а не файл**: одна строка «вопрос → папка».
Исключение — входные точки `00_system` и реестр не-сделанного: их читают до задачи.

## Потолок корня

Корень не перечисляет заметки. **Выросший корень — дефект, а не история:** каждая строка в нём
платится в каждой задаче, потому что §12 правил велит открыть его перед работой. Появилось желание
дописать заметку в корень — значит она нужна в под-индексе своей папки.

## Запрещено

- Держать файл без записи в под-индексе своей папки — такой файл «не существует».
- Держать мёртвые ссылки в любом индексе.
- Возвращать в корень перечень заметок.

## Дата внизу

Обновляй строку `_Обновлён: YYYY-MM-DD_` при каждом изменении корневого индекса.
