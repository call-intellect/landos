# LINKING RULES

## Формат ссылок
- Внутри second-brain: `[[папка/файл|Текст]]`
- На код: указывать путь `src/module/file.ts:42`
- На внешнее: обычный markdown `[текст](url)`

## Обязательные ссылки
- Каждый файл содержит ссылку `[[../index|← index]]` внизу
- Каждый файл в index.md — иначе он не существует

## Правило перелинковки
Если упоминаешь концепцию, для которой есть файл — ставь ссылку.
Не злоупотребляй: только если ссылка реально полезна.

[[../index|← index]]
