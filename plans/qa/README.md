# QA — единый трекер багов и приёмки

> Папка живого контроля качества. Здесь — **что нашли, что починили, что перепроверили**. Не отчёт-однодневка, а трекер с жизненным циклом каждого бага.

## Зачем папка

Результаты прогонов легко разъезжаются по отдельным датированным файлам, и потом нельзя ответить «а этот баг в итоге починили или нет?». Эта папка сводит всё в **один реестр** с галочкой «исправился / не исправился» и стабильным ID на каждый баг.

## Как устроено

| Файл / папка | Что это |
|---|---|
| `bugs-registry.md` | **Единый живой реестр** всех багов. Источник правды о статусе. Один баг = одна строка со стабильным ID (шаблон — `bugs-registry.template.md`). |
| `sessions/` | Отчёты прогонов тестировщика (по дате). Подробности «как воспроизвёл», скриншоты, трейсы. Реестр ссылается сюда. |

## Жизненный цикл бага (статусы)

```
🆕 найден  →  📝 ТЗ написано  →  🔧 исправлено (ждёт ретеста)  →  ✅ проверен-исправлен
                                                              ↘  ❌ проверен-НЕ-исправлен  →  (reopen, назад в 📝/🔧)
```

Доп. статусы: `⏸️ отложен` (есть причина), `🚫 не баг / отклонён`.

**Severity:** `P0` (блокер — раздел/функция нерабочая) · `P1` (серьёзно, но есть обход) · `P2` (заметно, не критично) · `P3` (косметика/копирайт).

## Процесс (цикл)

1. **Нашли баг** (ручной тест или диагностика) → строка в `bugs-registry.md`, статус `🆕`, severity, раздел, симптом, доказательство (скрин/трейс), ссылка на сессию.
2. **Написали ТЗ** на фикс (`plans/tz/`) → статус `📝`, ссылка на ТЗ.
3. **Починили** (коммит) → статус `🔧`, ссылка на коммит.
4. **Перепроверили** → `✅` (закрыт) либо `❌` (reopen с новым доказательством).

Правило: статус `✅` ставится **только после живого ретеста**, не по факту коммита (коммит ≠ работает в бою).

## Доступы (для тестировщика)

Креды тестового окружения держи в **gitignored-файле** вне этого каталога (например `.qa-cabinet.local.json` в корне проекта). В реестр и сессии их НЕ вписывай, в чат не печатай. Диагностику по данным делай read-only и только с явного разрешения владельца.
