## 1. ⚠️ Главное предупреждение про `.env`

Корневой `/.env` может быть настроен под **ПРОД** (боевые секреты, прод-хосты БД/Redis, прод-домены cookie).

**Поэтому:**
- НЕ запускай локалку командой, которая тянет прод-`.env`.
- Корневой `/.env` не трогаем, не коммитим, не выводим.
- Локальный конфиг живёт в отдельном gitignored-файле (например `app/.env` / `.env.local`), с `NODE_ENV=development` (или аналогом).
- Помни ловушки dev-режима: например secure-cookie по https сломает логин на `http://localhost` — нужен dev-флаг.
