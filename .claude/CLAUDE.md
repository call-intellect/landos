## Код проекта — индекс первым
- `make_context_capsule` (RepoBrain) — на ЛЮБОЙ задаче до `grep`/`glob`/`Read`: по формулировке задачи отдаёт ранжированную капсулу контекста.
- **Английские имена кода — самый точный запрос** (`createLead`, `LeadInput`): поиск по коду лексический. Русский запрос тупиком больше не является: он находит заметки `second-brain/` и через них — описанный ими код (мост «заметка → код», волна 2). Не нашлось по-русски — перезапроси английскими именами, а не решай, что кода нет.
- «Скелет» файла вместо полного `Read`; `Read` — когда нужна точная строка для правки.
- Сырой `grep` — только когда индекс недоступен или нужен буквальный матч по строке.
