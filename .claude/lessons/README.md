# Реестр уроков: подсказка в момент действия

`registry.jsonl` — один урок = одна строка JSON. Урок подаётся хуком `.claude/hooks/lesson-hint.py`
**до** выполнения команды (`PreToolUse:Bash`) и **на её падении** (`PostToolUseFailure`). Хук ничего
не блокирует: он печатает `additionalContext` и всегда выходит кодом `0`.

Формат «одна строка = один урок» выбран ради дельт: добавить урок — дописать строку, ни одна
существующая не переписывается.

## Поля строки

| Поле | Что это |
|---|---|
| `id` | `L001`, `L002`, … |
| `status` | `active` (подаётся) или `parked` (лежит, не подаётся) |
| `trigger.tool` | имя инструмента (`Bash`) или `*` |
| `trigger.match` | регулярное выражение Python по тексту команды (на падении — по команде и тексту ошибки) |
| `trigger.event` | необязательное: подавать только на этом событии (`PostToolUseFailure`) |
| `trigger.repeat_failures` | необязательное: подавать, только когда та же команда упала N-й раз в этой сессии |
| `hint` | одна–две строки. **Факт и следующий шаг, а не приказ** — подсказка ценна сменой траектории, не текстом |
| `scope` | роли/скиллы, к которым урок относится; `["*"]` — ко всем |
| `source` | где живёт человеческая версия урока |
| `proof` | доказательство (см. ворота ниже) |
| `checked` | чем именно проверено |
| `pattern` | как этот класс ошибки выглядит со стороны |
| `dead_end` | «так пробовали — не работает, потому что…» |

`proof`, `checked`, `pattern`, `dead_end` — те самые три поля порога плюс доказательство. Пустое хотя
бы одно у активного урока — прибор `self_learning` считает строку в `lessons_incomplete`.

## Ворота на повышение

Урок заводится со `status: parked`. В `active` он переводится, когда в `proof` названо одно из:

- **прибор с числом** — `probe:<id>`, который сдвинулся в нужную сторону, и ни один другой не
  ухудшился;
- **сценарий стенда** — `scenario:<id>`, зачёт которого вырос с «менее 2 из 3» до «2 из 3 и выше»
  при аблации (без урока сценарий краснеет);
- **документированный инцидент** — `incident:<файл>[,<файл>]`, где грабля зафиксирована с датой и
  разбором. Это ослабленная форма: она допускается только для граблей, на которые кит наступал
  **повторно**, и обязана быть заменена сценарием, как только тот появится. Строка «сценарии под
  L002–L006» стоит в `second-brain/04_not-done/README.md` с триггером «урок повторился после подачи».

Отдельного числового порога сдвига не вводим: пороги уже заданы в `meta.target` каждого прибора.

## Счётчики

Счётчик подач живёт **не в файле урока**, а в телеметрии стенда: `.git/lesson-hints.jsonl`
(не отслеживается git, ротация в `.jsonl.1` при 1 МБ). Причина: файл урока едет в git и в архив
клиента, а счётчик, растущий на каждый вызов `Bash`, дал бы шум в истории и конфликты между
параллельными сессиями. Область применения (`scope`) — наоборот, в файле: это знание, а не телеметрия.

Прибор `self_learning` печатает `lessons_active`, `lessons_without_proof`, `lessons_incomplete`,
`hooks_that_teach` и `hints_delivered` (подачи за 7 дней).

## Проверить руками

```bash
echo '{"hook_event_name":"PreToolUse","tool_name":"Bash","tool_input":{"command":"git add -A"},"session_id":"t1"}' \
  | CLAUDE_PROJECT_DIR=$PWD python3 .claude/hooks/lesson-hint.py; echo "exit=$?"
```

Ожидаемо: `exit=0` и JSON, в котором `additionalContext` содержит `git add <путь>`. На честной
команде (`git add src/page.js`) вывод пустой, код тот же `0`.
