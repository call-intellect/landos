TEMPLATE — замени на реальное поведенческое правило, выведенное из фидбека/ошибки.

**Why:** один поиск по коду (RepoBrain или tool поиска) вернул «нет совпадений», на основании чего код был помечен мёртвым и чуть не удалён — а прямое чтение файла показало реальный вызов. Поиск дал ложный минус; удаление сломало бы поведение.

**How to apply:** перед выводом «X не используется / отсутствует» — особенно перед удалением — подтверди чтением файла (Read), а не одним поиском. Поиск — подсказка, не вердикт.
